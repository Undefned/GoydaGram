## 🎯 Социальная сеть GoydaGram — Кратко (Актуализировано)

### 📱 Основная концепция
Платформа для короткого вертикального видео и пользовательского контента (аналог TikTok/Reels). Основной фокус — умная лента на основе интересов пользователя и мгновенная подача контента.

---

## 🔥 Ключевые фичи (Базовый функционал)

1. **Пользователи** — регистрация, профили, аватарки, система подписок (User Service).
2. **Контент** — загрузка видео, HLS-стриминг, генерация превью, хранение в S3-совместимом хранилище (Content Service).
3. **Социальные действия** — лайки, комментарии, сбор просмотров и интересов (Social Service).
4. **Умная лента** — формируется динамически на основе очереди интересов пользователя с предзагрузкой пачек контента (Feed Service).
5. **Поиск** — полнотекстовый поиск по пользователям и описанию/тегам видео (Search Service + Elasticsearch).
