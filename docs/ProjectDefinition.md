## 🎯 **Социальная сеть GoydaGram — кратко**

### 📱 **Основная концепция**
Платформа для коротких видео (как TikTok/Reels)

---

## 🔥 **Ключевые фичи**

### **Базовый функционал:**
1. **Пользователи** — регистрация, профили, аватарки, подписки
2. **Видео** — загрузка, обработка, HLS стриминг, превью
3. **Социальные действия** — лайки, комментарии
4. **Лента** — умная сортировка (от подписок/популярное/новое)
5. **Поиск** — по пользователям и видео (по тегам/описанию)
6. **Мессенджер(?)** — переписки с кентами
7. **Настройки** — настройки

---

### 🚀 **Уникальные фичи(на подумать):**

#### **Watch Party (Комнаты просмотра)**
- Создание приватных комнат для синхронного просмотра с друзьями
- Общий чат справа от видео
- Ведущий управляет плеером (пауза/плей у всех)

#### **Frame Hunter (Охотник за кадрами)**
- Можно отметить любой кадр видео как "шедевр"
- Собирается галерея лучших кадров
- Лайки отдельным кадрам

---

## 🏗 **Архитектура (микросервисы)**

```
1. User Service        → профили, подписки, онлайн-статусы (PostgreSQL + Redis)
2. Video Service       → загрузка, хранение, лента видео (PostgreSQL + MinIO)
3. Social Service      → лайки, комментарии, real-time (PostgreSQL + Redis)
4. Messenger           → чаты
   
RabbitMQ → асинхронные события (новые видео, лайки, подписки)
Redis   → кеш, онлайн-статусы, временные данные комнат
MinIO   → хранение видеофайлов
```

---

## 📊 **Технические фишки под требования:**

✅ **CQRS** — отдельная read-модель для ленты видео  
✅ **Inbox pattern** — идемпотентная обработка событий  
✅ **Event-Driven** — события через RabbitMQ (новое видео, лайк, подписка)  
✅ **Database per service** — у каждого своя БД  
✅ **Redis cache** — онлайн-статусы, топ комментарии  
✅ **Correlation ID** — сквозное логирование  
✅ **Prometheus + Grafana** — метрики  
✅ **Loki** — централизованные логи  
✅ **JWT** — авторизация  
✅ **Swagger** — документация API  
✅ **Docker Compose** — запуск одной командой
